# C++ машинаға бағытталған бағдарламалау — GitHub Pages

## GitHub-қа орналастыру
1. ZIP архивін компьютерге жүктеп, **Extract All** жасаңыз.
2. GitHub-та Public repository ашыңыз.
3. Архивтен шыққан файлдардың барлығын repository-дің негізгі бетіне жүктеңіз.
4. `index.html` файлымен бірге `assets` және `source` папкалары да сол негізгі деңгейде тұруы керек.
5. `Settings → Pages → Deploy from a branch → main → /(root) → Save` таңдаңыз.
6. Бірнеше минуттан кейін GitHub Pages адресін ашыңыз.

Құрылым:

```text
index.html
app.js
styles.css
book-data.js
assets/cover-final-2026.jpg
source/lectures.pdf
source/labs.pdf
```

## Ескерту
Материалдардың мазмұны берілген PDF дереккөздеріне негізделген. Сайт PDF беттерін жоғары сапада көрсету үшін PDF.js қолданады.
